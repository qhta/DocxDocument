The OpenXml ChartDrawings namespace defines a set of types and elements for representing, 
structuring, and rendering graphical objects associated with charts in Office Open XML documents.
This namespace is primarily used to describe drawing elements linked to charts, 
including shapes, connectors, graphical frames, and text boxes.
Key features of the ChartDrawings namespace include:
- Positioning and anchoring of graphical objects relative to chart elements.
- Definition of non-visual properties such as unique identifiers, names, and metadata for shapes and connectors.
- Specification of visual properties, including geometry, fill, line formatting, and visual effects.
- Support for grouping, layering, and organizing drawing objects to enable complex chart annotations and overlays.
- Integration with chart data to provide context-aware graphics, such as callouts, highlights, and custom annotations.
•	ChartDrawings is not part of the official Open XML standard and should only be used 
if your project specifically defines or requires it.
